# Contributing

Issues are welcome; pull requests by arrangement, with DCO sign-off.

Open an issue for a wrong command, a missing case or a skill you would like. For a pull request, agree on it in an issue first, and sign off every commit (`git commit -s`) to certify the [Developer Certificate of Origin](https://developercertificate.org/).

Before sending a change, run `make check`. Every command and flag in a skill must exist in the nfltr release the Makefile pins.
